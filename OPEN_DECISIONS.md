# Open decisions

Things that were built on a best guess, deviate from a plan, or need a person (Vincent or the designer) to confirm. Each row says what the code does today, so a decision can be made without reading the diff. When one is settled, move it to "Settled" with the date and the call, and update the code or plan if it changed.

Source: the first implementation pass of NEXT_PLAN (WP-C, WP-A, WP-B0), PR #3; Build 2 (Standing, switching, quest copy) added D14-D22; Build 3 settled D3 / D5 / D23; Builds 4–6 wrote Route 2, the Cobblecrest Sacrifice stub, and Rook's R5. Every Standing number and string named below lives in `STANDING_CFG` (`standing.js`), so a decision is a one-line change there. Explicit `["standing", side, n, id]` amounts in scenes do not need a `grants` row. Q16 landed the Act 1 stack. The party board, the installable app, look and listen, and the Lantern Council are built. Rename, the music volume slider, and the welcome-back line are Q23–Q25. The next build stays town boards (Q19, D37–D49). Q26, modern and arcade controls, is scoped and not started. Which branch held which piece is in `BRANCH_LOG.md`.
