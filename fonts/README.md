# Fonts

`Jersey15.woff2` is **Jersey 15** by Sarah Cadigan-Fried (The Soft Type Project,
https://github.com/scfried/soft-type-jersey), from the Google Fonts repository
(`ofl/jersey15/Jersey15-Regular.ttf`). It is licensed under the SIL Open Font License 1.1;
the full license is in `OFL.txt`.

The file here is a Latin subset converted to WOFF2 (Basic Latin, Latin-1, a few punctuation marks)
to keep it small (~15 KB). Symbols the font doesn't have (★ ♥ ▲ ◀ ▶ ▼) fall back to the system font.
